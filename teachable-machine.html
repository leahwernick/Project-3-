Teachable Machine

Google's Teachable Machine is a free, browser-based tool that lets anyone train a basic machine learning model — no coding experience required. You provide examples, the model learns from them, and it can then classify new inputs in real time. It's an accessible entry point into understanding how AI and machine learning actually work.

This kind of hands-on tool helps reveal something important: machine learning models are only as good as the data they're trained on. Who provides the examples? Whose faces, voices, or gestures are included? These questions connect directly to the themes of bias, power, and representation we explore in LIS 500.

What We Learned

Working with Teachable Machine helped us see machine learning not as an abstract, distant technology, but as something we can interact with and critique. Training the model ourselves made the process more transparent — we could see exactly what data went in and how it influenced what came out.

This experience reinforced a key idea from LIS 500: technology is not neutral. Every machine learning model reflects the choices of whoever built and trained it — what categories they chose, whose data they used, and what they decided to leave out. Recognizing this is the first step toward building more equitable and accountable systems.
